Who this guide is for

The two administration roles that keep the whole CRM running.

RoleWhat you doWhat only you can do
Super AdminOwns the entire systemEverything, incl. "Preview Roles" and locking the Super Admin role
Process AdminRuns day-to-day setupUsers, projects, automations, integrations (cannot override the Super Admin lock)
Difference in one line: Super Admin can do everything; Process Admin does everyday setup and configuration but a few owner-only controls stay with the Super Admin.

Your home screen

After you log in you land on the Dashboard. The left menu is grouped into Overview, Sales, Deals & Finance, Messaging, Automation & Setup, Partners and Administration (the section you'll use most).

Tip: Press Ctrl + K (Windows) or Cmd + K (Mac) anywhere to search a lead or jump to any page instantly.

Logging in for the first time

  1. Open the CRM link in your browser (Chrome or Edge recommended).
  2. On the sign-in screen, type your email in the Email box.
  3. Type your password in the Password box.
  4. Click the black Sign in button.
  5. If it's your very first login, the system asks you to set a new password — type it twice and confirm.
  6. You now land on the Dashboard.

TASK 1 — Complete the first-time company setup

The very first Admin is guided through a short wizard. The side menu stays hidden while the wizard runs so you can focus; it reappears when you finish or skip to the dashboard.

1. Set up your profile
  1. Confirm your name and phone number.
  2. Pick an avatar colour (optional).
  3. Click Continue / Next.
2. Set up your first project
  1. Enter the project name (e.g. "Green Valley Plots").
  2. Enter the city and zone/locality.
  3. Choose the unit type (Plot, Apartment, Villa…).
  4. Enter the price range if asked.
  5. Click Save / Next.
3. Map your department users
  1. Add each team member's name, email (their login ID) and phone number (their first-time password).
  2. Pick their role from the list (Sales Head, BDE, Accounts Head…).
  3. Click Add user and repeat for everyone.
4. Upload inventory
  1. Add the phases and the plots/units for your project.
  2. Mark each unit's status (Available / Held / Booked / Sold).
5. Assign a Process Admin
  1. Choose a trusted team member to help run daily setup.
  2. Click Finish — the full menu now appears.
Need to redo the demo? On the dashboard, the setup banner has a Restart setup button that resets the wizard.

TASK 2 — Add a new user

  1. In the left menu, open Administration → Users & Roles.
  2. Click the Add user button (top right).
  3. Type the person's full name.
  4. Type their email — this becomes their login ID, so type it carefully.
  5. Type their phone number — this becomes their temporary password for the first login.
  6. Pick their role from the dropdown (this decides what they can see and do).
  7. Click Save.
  8. Tell the person their email and that their first password is their phone number.
  9. They will be forced to set a new password the first time they log in.
Note: Sending the welcome email is mocked until you connect a real email account in Integrations. Until then, share the login details yourself.

Turn a user on or off

  1. Open Users & Roles.
  2. Find the person's card (use the search box if the list is long).
  3. Use the active toggle on their card — off means they can no longer log in.

TASK 3 — Change what a role can do (Roles & Access)

  1. Open Administration → Roles & Access.
  2. On the left, click the role you want to change (e.g. "Accounts Support").
  3. The middle shows features grouped by area (Accounts & Finance, Messaging, etc.).
  4. Use the search box to find a specific feature quickly.
  5. Flip an individual toggle on to grant it, or off to remove it.
  6. Use the "All" switch on a group header to turn a whole group on or off.
  7. Click Save access (top right).
Two things to remember: (1) The Super Admin role is locked — you can't reduce its access. (2) Changes take effect the next time that user logs in.

Reset a role to its defaults

  1. Select the role. If it was changed, a Customised badge shows.
  2. Click Reset to default to restore the standard access for that role.

TASK 4 — Connect your own accounts (Integrations Hub)

This is where you switch the CRM from safe demo mode to sending real WhatsApp, email and calls. Only Admin and Process Admin can see this page.

General steps for any integration
  1. Open Administration → Integrations.
  2. Click the card you want to set up (Meta WhatsApp, Google Email or Mcube).
  3. Fill each field in the form. Fields marked * are required.
  4. Click Test connection and wait for the result.
  5. If you see a green tick, click Save.
  6. Turn the card's toggle on to go live.
Safety: Your passwords and tokens are encrypted and never shown again — you'll only ever see dots like ••••1234. You cannot turn an integration on until all required fields are filled, and if you change a field you must test again before it goes live.

Meta WhatsApp Cloud — fields

  • Phone number ID
  • Access token
  • Verify token (for the webhook)

Google Workspace Email — fields

  • SMTP host (default smtp.gmail.com) and port (default 587)
  • Username (the dedicated mailbox address)
  • App password (generated in Google — not the normal password)
  • From name and from email

Mcube — fields

  • Base URL
  • Auth token
  • Caller ID
Before you start: get your credentials ready with your IT person. You paste them into the CRM form — never into chat or email.

TASK 5 — Build an automation (Flow Builder)

  1. Open Automation & Setup → Flow Builder.
  2. Click Starter flows to begin from a ready-made journey (recommended), or start blank.
  3. Drag a Trigger block onto the canvas (e.g. "On new lead").
  4. Drag action blocks — Send WhatsApp, Send Email, Create Task, Wait / Delay, Condition.
  5. Connect blocks by dragging from one block's dot to the next.
  6. Click a block to configure it in the right-hand Node settings panel.
  7. Use the Mission checklist (bottom right) to create any templates the flow needs.
  8. Click Validate, then Save flow.
  9. Click Test run to try it, then Activate to make it live.
Good to know: An active flow runs automatically when its trigger happens for a real lead. If a step fails, it is marked as failed (not silently skipped) so you can see it.

TASK 6 — Check system health & the audit log

  1. Open Administration → System Health to see message volume, automation success and search latency. "MOCK" means that integration is still in demo mode.
  2. Open Administration → Audit Log to see exactly who changed what, and when.
  3. Use the filters at the top of the Audit Log to narrow by action or by entity type (e.g. "Lead").

TASK 7 — See the app as another role (Preview Roles)

  1. Open Administration → Preview Roles (Super Admin only).
  2. Choose the role you want to preview.
  3. The CRM now shows exactly what that role sees — useful before you hand access to a team.
  4. Exit preview to return to your own view.
